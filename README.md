## ⭐ 快速开始（不知道用哪个？）

- **零基础培养习惯**：Duolingo（多邻国）＋ 每日英语听力
- **背单词**：Anki（可定制、免费）／ 墨墨背单词 ／ 不背单词
- **练口语发音**：ELSA Speak（AI 纠音）＋ 影子跟读法（见 [`methods.md`](./methods.md)）
- **提升写作**：Grammarly ＋ DeepL ＋ 《English Grammar in Use》
- **看剧学英语**：Netflix / YouTube ＋ Language Reactor（双语字幕）
- **系统打基础**：BBC Learning English ＋《新概念英语》
- **找真人交流**：italki（外教）／ HelloTalk（语伴）

## 🧭 收录原则

1. **确实有用、口碑稳定**，优先收录经过大量学习者验证的资源。
2. 每条附**一句话说明**，讲清它解决什么问题、适合谁。
3. 链接以**官方网站**为准；如发现失效或描述有误，欢迎提 Issue / PR。
4. 同类资源择优收录，避免无差别堆砌。
